# 拆书记录：《东宫》

## 基本信息

- **作品 / 作者**：《东宫》/ 匪我思存（2019 剧版：陈星旭、彭小苒）
- **拆它的原因**：本文是 IF 同人，原著即考据对象+文风标杆，全部都要学

## 开篇拆解（原著结构）

- 原著用"失忆后东宫重逢"做主体，西州往事以回忆碎片穿插——甜与虐交替凌迟
- 楔子"忘川之水，在于忘情"一句话立住全书的宿命感

## 虐点结构（可复用的核心）

1. **糖中带毒**：最甜的场面（萤火虫、杀白眼狼王、大婚）全部预埋着毒——改写 IF 时，HE 也必须从"毒"里长出来，不能凭空甜
2. **记忆差即悲剧引擎**：谁先想起来，谁就先被判刑。原著小枫先想起来所以小枫死；李承鄞阵前最后一刻才想起来，"晚了一步"是全书最狠的一刀
3. **意象复现**：狐狸等姑娘的歌谣（开头=谶言，结尾=应验）、萤火虫（诺言的具象）、腰带（"系住他"的痴念）——同一个意象反复出现，每次含义加深一层

## 台词风格

- 小枫：短句、脆、带西州的野气和直球，骄傲不示弱（"我是西州九公主……我阿翁是丹蚩最厉害的铁达尔王"）
- 李承鄞：克制、少言、深情藏在动作里，朝堂话术的冷与私下对话的软形成反差
- 全书最痛的台词都是最平淡的句子（"现在是冬天了，没有萤火虫了"）

## 可复用到本文的

1. 三章结构 = 三个意象锚点：断剑（改命）→ 空腰带（偿还）→ 萤火虫（等到）
2. "谁先想起来谁被判刑"这条引擎反过来用：IF 线让李承鄞先想起来，刑他来受
3. 虐后回甘的甜度控制：原谅不能一句话给，要让李承鄞"挣"——每天挣一点

## 要引以为戒的

- 不许洗白灭族：丹蚩的血是既定事实，IF 线只改"之后的选择"，不改"已发生之恶"
- 小枫不能圣母化：她可以活下来，但原谅必须是长过程，否则 OOC
