# 设定取舍（原著考据）

## 保留的原著设定（不可改）

- 丹蚩灭族、阿翁铁达尔王之死、大婚血案——既定事实，IF 线不洗白
- 忘川与三年失忆、东宫重逢、小枫先恢复记忆——前史全部保留
- 意象系统：狐狸等姑娘的歌谣、一百只萤火虫、腰带、白眼狼王
- 两军阵前的地点（玉门关外）与白衣自刎的原著场面

## IF 分歧点

**阵前改命**：小枫横剑自刎的那一瞬，李承鄞丢下佩剑、当众退兵。
原著里他"最后一刻想起来，晚了一步"；本文他"最后一刻想起来，赶上了"。

## 本文的魔改（写明理由）

- 李承鄞在阵前当众恢复全部记忆（原著是之后独自想起）——理由：让他"先被判刑"，刑期才有观众
- 退兵条件：李承鄞自请废去太子之位、留质西州三年——理由：HE 必须有等价的代价，否则原谅廉价
