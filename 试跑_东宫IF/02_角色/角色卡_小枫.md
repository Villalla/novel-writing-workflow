# 角色卡：小枫（玛尔其玛）

## 基本信息

- **姓名 / 称呼**：小枫，西州九公主，玛尔其玛
- **年龄 / 身份**：18 岁，西州九公主，母系丹蚩王族
- **外貌关键词**：红裙、大漠、笑起来有光的眼睛

## 性格 ★

- **性格锚点**：明媚炽烈 / 宁折不弯 / 至情至性
- **核心欲望**：自由地爱与被爱，一份不掺算计的真情
- **恐惧/雷点**：被欺骗；家国因她而亡的负罪；绝不示弱、绝不乞怜
- **缺陷**：爱恨都太满，不给自己留退路

## 说话方式 ★

- **口癖/习惯用语**：自称"我"不称"本宫"（私下）；生气时直呼其名
- **语速与句式**：短句、脆、直球，带西州的野气；骄傲时用排比自报家门
- **对不同人的态度差异**：对李承鄞爱时全信、恨时全决；对阿渡是姐妹式的软

## 人物弧线（本文 IF 线）

- **起点状态**：阵前求死，恨到尽头只剩一句"祝你坐拥万里江山，享无边孤寂"
- **转折点**：他没接那句祝福，反而丢了剑——她的"死"被剥夺了意义
- **终点状态**：活下来，学会把恨和爱分开存放，自己选择给一次"等"

## 秘密与关系

- **秘密**：自刎那一刻她想的不是恨，是萤火虫——她到死都在等顾小五回来
- **关键关系**：李承鄞（爱人与仇人同体）；阿渡（唯一的娘家人）

## 声线样本 ★

1. "我是西州九公主，我父王是西州的国主，我母亲是丹蚩王的女儿，我阿翁是丹蚩最厉害的铁达尔王。"
2. "顾小五，你给我捉一百只萤火虫，我就死心塌地地嫁给你。"
3. "我的顾小五已经死了。"
4. "生生世世，我都要永远忘了你。"
5. "祝你坐拥万里江山，享无边孤寂。"
