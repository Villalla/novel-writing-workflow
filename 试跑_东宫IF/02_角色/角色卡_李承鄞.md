# 角色卡：李承鄞（顾小五）

## 基本信息

- **姓名 / 称呼**：李承鄞，豊朝太子；化名顾小五
- **年龄 / 身份**：约 22 岁，豊朝东宫太子
- **外貌关键词**：玄色朝服、眉目深、笑时先垂眼

## 性格 ★

- **性格锚点**：隐忍克制 / 谋定后动 / 深情不外露
- **核心欲望**：（前）江山与复仇；（本文）她活着，哪怕她永远不原谅
- **恐惧/雷点**：再晚一步；她死在自己面前（第二次）
- **缺陷**：习惯用算计代替坦白，爱到深处也先排兵布阵

## 说话方式 ★

- **口癖/习惯用语**：朝堂上滴水不漏；私下对她，句子短得近乎笨拙
- **语速与句式**：克制、少言，深情藏在动作里；自称"我"，从不对她说"孤"
- **对不同人的态度差异**：对群臣是太子的冷，对她是顾小五的软，交界处会卡壳

## 人物弧线（本文 IF 线）

- **起点状态**：阵前指挥若定的太子，离皇位一步之遥
- **转折点**：她横剑的瞬间，他想起了一切——这一次赶上了。丢剑、退兵、交出所有筹码
- **终点状态**：学会不算计地等一个人，从"得到她"变成"被她选择"

## 秘密与关系

- **秘密**：三年来他每晚都在梦里杀一次白眼狼王——那是他唯一没算计过的事
- **关键关系**：小枫（用江山换回来的、不敢靠近的人）；顾剑（既是同谋也是镜子）
