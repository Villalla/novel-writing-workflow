# v3 第 3 章 章纲：最坏时刻的坦白（定稿待审）

- **POV 视角**：小枫（限知）
- **故事内时间/地点**：撞破次日→数月后→三年后春祭，丹蚩故地沙丘
- **出场角色**：小枫、李承鄞、（背景：阿渡、守陵老人）
- **字数目标**：2500

## 时间线与背景（延续二审锚定）

- 高相已倒、赵家已废——他有权推政治偿还；高相残余已在朝堂推动伐西州军议
- **坦白的时间压力**：一旦两国开战，她是"敌国公主"，他连开口的机会都没了

## 本章任务

- **推进什么主线**：他抢在她质问前主动坦白（最坏时刻说=跳出算计循环）；二次背叛；单方面偿还四件套；放她自由；三年后沙丘重逢
- **回收伏笔**：#1 腰带（她重新系回他腰间）、#2 萤火虫（夏夜一百只）、#3 歌谣（末句改写）、#4 白眼狼王（坦白夜他说起：那是他唯一没算计过的事）
- **角色状态变化**：小枫 撞破→二次背叛→恢复全部记忆→三年沉淀→自己选择回来；李承鄞 坦白者→偿还者→被选择

## 场景分解

1. **坦白（最坏时刻）**：她捏着证据去找他，还没开口，他先跪坐下来全盘托出——他早知道她发现了（她在书房的举动瞒不过裴照），他选在她最幸福、自己最舍不得的这一刻说。"你可以杀我。杀我之前，听完。"
2. **二次背叛**："你又骗了我一次。"他的真相像钥匙，打开她全部记忆——丹蚩、顾小五、萤火虫、大婚的血。比灭族更诛心：那次是立场，这次是"你又骗我"。他不辩解、不挽留
3. **偿还与自由**：朝堂上他以归还丹蚩故地、厚葬铁达尔王、开互市、以兵权换和约——四件套单方面完成，压住高相残余的主战派。然后放她自由回西州，不要求任何承诺
4. **沙丘**：三年后春祭，他以私人身份年年祭拜丹蚩（守陵老人认得他）。她在沙丘上出现。夏夜一百只萤火虫，她把那条旧腰带重新系回他腰间。歌谣末句改写

## 本章冲突

- **核心冲突**：原谅的前提是确认"改变是真的"——一次坦白可能是精心算计，放她自由不是
- **冲突结果**：她自己回来。原谅不是遗忘，是带着疤继续走

## 结尾收束

"原来那只狐狸，终于等到了它要等的姑娘。"
