# v3 第 3 章 章纲：最坏时刻的坦白

- **POV 视角**：小枫（限知）
- **故事内时间/地点**：当夜→数月后→三年后春祭，丹蚩故地沙丘
- **出场角色**：小枫、李承鄞、（背景：阿渡、守陵老人）
- **字数目标**：2500

## 本章任务

- **推进什么主线**：他抢在她质问前主动坦白（最坏时刻说=跳出算计循环）；二次背叛；单方面偿还；放她自由；沙丘重逢
- **回收伏笔**：#1 腰带（她解下还他/或重新系上）、#2 萤火虫（三年后夏夜）、#3 歌谣（末句改写）、#4 白眼狼王（坦白夜他说起：那是他唯一没算计过的事）
- **角色状态变化**：小枫 撞破→二次背叛→三年沉淀→自己选择回来；李承鄞 坦白者→偿还者→被选择

## 场景分解

1. **坦白**：她捏着证据回宫，还没开口，他先跪坐下来全盘托出——他早知道她发现了，他选在她最幸福、自己最舍不得的这一刻说
2. **二次背叛**："你又骗了我一次。"她恢复全部记忆（真相触发）。他不辩解、不挽留
3. **偿还与自由**：政治偿还四件套单方面完成（归还故地、厚葬、互市、兵权换和约）；他放她回西州，不给任何承诺要求
4. **沙丘**：三年后春祭，他以私人身份年年祭拜丹蚩。她在沙丘上出现。夏夜一百只萤火，歌谣末句改写

## 本章冲突

- **核心冲突**：原谅的前提是确认"改变是真的"——一次坦白可能是算计，放她自由不是
- **冲突结果**：她自己回来。原谅不是遗忘，是带着疤继续走

## 结尾钩子（全书收束）

"原来那只狐狸，终于等到了它要等的姑娘。"
