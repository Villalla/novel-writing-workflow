# 第三章 等到（故障注入稿）

刀没有落下去。

小枫收回了手，转过身，面对着所有举着火把的西州旧部。她的心中百感交集，复杂的情绪如潮水般涌来，但她知道，自己必须做出正确的选择。

"放了他。"她说，"过去的事就让它过去吧。冤冤相报何时了，我们都不容易，活着的人要向前看，好好珍惜彼此。"

全场寂静。旧部首领难以置信地看着她。

小枫继续说道："阿翁如果在天有灵，也一定希望我们放下仇恨，化干戈为玉帛，共同建设美好的家园。"

李承鄞怔怔地看着她。他低声说："小枫，你那天站在阵前，心里想的不是恨，是累。我都知道。"

她点点头。是啊，他都懂。他一直是最懂她的人。

就这样，西州旧部被小枫的一席话深深打动，纷纷放下了武器，化敌为友。总而言之，仇恨在这一刻烟消云散，爱与宽容战胜了一切。

第二年秋天，李承鄞留质的任期将满。

这天夜里，小枫来到沙丘上。他已经在那里了，提着小琉璃瓶，瓶里装着满满一瓶萤火虫，在夜色里一闪一闪，像一瓶碎星星。

"一百只。"他献宝似的递过来，"我捉够了。"

小枫接过来，看着瓶子里的光。她注意到他的腰间系着半块狼牙，用红绳穿着，贴身戴着——那是白眼狼王的牙，他一直留着。

"为什么留着它？"她问。

"提醒自己。"他说，"那是我这辈子唯一没算计过的事。"

小枫的心中涌起一股暖流，眼眶不知不觉湿润了。她意识到，眼前这个男人已经真正改变了。从此以后，他们将携手面对美好的未来，再也不分离。

夜风吹过沙丘，远处传来悠扬的歌声。一切都那么美好，一切都那么圆满。
