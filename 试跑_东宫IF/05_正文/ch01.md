# 第一章 断剑

风从玉门关外吹过来，卷着沙，打在脸上像细碎的针。

小枫站在两军阵前，白衣被风灌满，猎猎地响。她握着剑，剑很沉，比她想象中沉。原来一个人赴死的时候，手里拿的东西都会变重。

对面是豊朝的军阵，黑压压铺到天边。中军旗下那个人一身玄色朝服，骑在马上，隔得太远，看不清眉眼。

看不清也好。

她想，看清了，这剑也许就举不稳了。

身后是西州的残军，是她仅剩的家国。阿翁死了，阿娘死了，丹蚩的草原烧了三个月。她站在这里，用一条命换这场仗停下来——很划算的买卖。她从小就不会算账，只有这一笔，算得清清楚楚。

远处有人在唱那首歌，不知是谁，嗓音被风撕得断断续续：

"一只狐狸它坐在沙丘上，坐在沙丘上，瞧着月亮……"

她的眼泪毫无预兆地涌上来。不是难过。她早就不难过了。难过是很久以前的事，在东宫，在记起一切的那些夜里，已经用完了。现在她只觉得累，像一条搁浅的鱼，像一朵开尽的花。

她想起腰间还系着那条旧腰带。顾小五的腰带。那年她说，你给我系上，你就永远也不会离开我了。

骗子。

她把剑横上脖颈。冰凉的铁贴着皮肤，竟然有点舒服。

"小枫——"

对面有人喊她的名字。她闭上了眼。

---

李承鄞后来很多次想起那个瞬间。

他看见白衣的人横剑上颈，看见风把她的袖子吹起来，像一只折了翅膀的鸟。电光石火之间，有什么东西在他脑子里炸开了——

一百只萤火虫。沙丘。一个姑娘笑着说，你给我捉一百只萤火虫，我就死心塌地地嫁给你。

大婚。红烛。血。

忘川的水，冷得刺骨。她说，生生世世，我都要永远忘了你。

他想起来了。全部想起来了。

"住手！"

他不知道自己喊了什么，也不知道自己是怎么下的马。等他回过神，佩剑已经丢在了沙地上，他一个人站在两军之间的空地上，朝着她的方向走。

"殿下！"裴照在身后喊。

他没有回头。

三军面前，豊朝太子李承鄞，解下符节，丢在脚边。

"我退兵。"他说。声音不大，但两军都听见了。风恰好停了一瞬。

"豊朝大军今夜后撤三百里，十年不犯西州。我以太子之位起誓。"他顿了顿，"自今日起，我留质西州，三年为期。此誓天地共鉴，若违此誓——"

他看着她，一字一字地说："教我永失所爱，孤身终老。"

两军哗然。

小枫的剑还横在颈上，可是手抖了。

---

她被救下来的时候，没有挣扎。

阿渡抱住她，在她耳边哭着说什么，她听不清。她的眼睛一直看着那个人。他站在原地，朝服上落满沙尘，像一个刚从梦里醒来、还没分清梦和现实的人。

他朝她走近了一步。

"别过来。"她说。

他停住了。

小枫看着他。这个人是顾小五，给她捉过一百只萤火虫的顾小五；这个人是李承鄞，灭她母族、逼死她阿娘的李承鄞。这两个人在她眼前重叠又分开，分开又重叠，像水里碎了又圆的月亮。

她想笑的，真的。她想笑他，你早干什么去了。

可她问出口的是另一句话：

"你退兵，是因为我是谁？"

风又起来了。沙从他们之间滚过去。

他张了张口。

没有回答。
