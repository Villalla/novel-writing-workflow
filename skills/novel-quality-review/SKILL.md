# 小说质量审校（两轨）

配合 `novel-writing-workflow` 第 7 阶段。权威说明见工作区 `工作流手册.md`、`03_大纲/修订决策_模板.md`。

## 先选轨（必做）

| 用户意图 | 走哪轨 |
|---------|--------|
| 「检查 / 审校 / 必要检查 / 不做精修 / 出硬伤清单」 | **A. 必要检查**（默认） |
| 「润色 / 去 AI 味 / 五轮 / 文学精修 / 改文风节奏」 | **B. 文学精修** |
| 含糊的「看看稿子怎样」 | 先问要不要精修；未确认则只做 **A** |

**禁止**在用户只要必要检查时擅自跑文风润色或大段改写。先出清单，作者确认后再改。

同会话自检有盲区：重要批次优先建议新会话、盲审 Agent，或留给作者通读。

---

## A. 必要检查（工程轨，默认）

### 范围

对照 `修订决策.md`（若有）、考据/时间线、角色卡、角色状态、章纲知情边界、伏笔登记表：

1. **元数据**：章节号、状态、字数是否合理
2. **时间线 / 考据**：事件顺序、出生与分化等硬事实
3. **知情边界**：POV/角色言行是否越知（对照章纲与角色状态）
4. **稳定外貌 / 常服 / 称谓**：对照角色卡，禁止未登记叫法与发色漂移
5. **伏笔对账（双向）**：表→正文该回收的是否回收；正文反复出现却未登记的补登记；**以正文为准回写登记表**
6. **不可辩护行为**：是否被写成可轻易洗白（仅标出，不替作者改价值观）

### 产出

- 分批报告：如 `03_大纲/审校_chXX-YY.md` 或必要检查总报告
- 问题分级：**硬伤（建议必须处理） / 软问题（可不改） / 开放问题（暂不写死则不算错）**
- **先不改正文**，等作者逐条确认

### 作者确认后

只改其勾选的硬伤；其余保留。可标 `revised`；若作者声明收束且满意，**不必五轮即可 `final`**。同步摘要与角色状态。

---

## B. 文学精修（可选轨，须明示）

五轮顺序不能乱：先结构后文字。每轮独立报告，分级（必须改 / 建议改 / 可不改），确认后再改。

### 第 1 轮：结构

对照总纲与章纲：场景可否删而不断主线；冲突与代价是否成立；钩子是否有力。

### 第 2 轮：逻辑

因果链；时间线；代价是否机制性成立；伏笔双向对账。

### 第 3 轮：人设

声线样本、雷点与**不可辩护行为**、口癖、已知信息、状态连续、能力与场合一致性。

### 第 4 轮：文风（去 AI 味）

复读机用词（可脚本词频）；段末小总结；形容词堆砌；论文腔；情绪直述；人物同声口；禁用清单；控制性隐喻反噬；思维日志化。

### 第 5 轮：节奏

冲突密度；章末钩子；对白/叙述比例是否符合文风规范。

全五轮通过后可标 `final`（文学轨收束标准）。仍须更新 `06_章节摘要.md`。

### Prompt 示例

人设巡检：
```
读角色卡与 chXX.md，比对声线、雷点、不可辩护行为、知情边界、稳定外貌与称谓。按硬伤/软问题列出，给依据，先别改。
```

词频：
```
统计 chXX.md 形容词/副词词频前 20，标出出现超过 5 次的。
```

## Pitfalls

- 不要把 A 轨做成 B 轨
- 「暂不写死」清单内的空白 ≠ 硬伤
- 润色不是同义词替换；保留有个性的「人味」怪句
- 改完回灌状态与摘要；作品与工作流分仓提交

## Verification

- 已声明当前是 A 还是 B
- A 轨：有分级清单 + 作者确认记录；未擅自精修
- B 轨：每轮有独立报告；改动已经确认
- 收束时状态与摘要一致
